# PC_Builder  
Demo Project for PC Building Site  
Developed by Kutay Söker

## 🎯 Proje Hakkında  
Bu proje, “Gelişmiş İnternet Programlama” dersi kapsamında geliştirilmiş bir PC toplama/sistem öneri web sitesi demo versiyonudur.  
Kullanıcıların farklı bilgisayar bileşenlerini seçerek kendi PC yapılarını oluşturabileceği ve öneriler alabileceği bir arayüz sunar.

## 🧩 Kullanılan Teknolojiler  
- TypeScript  
- React  
- Vite  
- HTML & CSS  
- (Gerekiyorsa) Ek kütüphaneler: ESLint, …  
- Veri katmanı ve backend örneği içeriyorsa belirtilebilir (örneğin: REST API, JSON dosyası vb)

## 🧑‍💻 Proje Özellikleri

Bilgisayar bileşeni kategorilerinin listelenmesi

Kullanıcının bileşen seçimine göre sistem oluşturabilmesi

Öneri alınabilmesi / seçimi tamamlanmış sistemin görüntülenmesi

Responsive tasarım

Basit ama işlevsel arayüz
